# Livinni Crochet Store 👜✨

A modern and responsive landing page for a handmade crochet store, designed to showcase products with an elegant and minimalist style.

The project was developed using only **HTML5 and CSS3**, focusing on clean structure, responsive design, and a premium shopping experience.

## Preview

A product showcase section with a carousel-style layout to display crochet bags and handmade items.

## Features

- ✨ Elegant black and gold visual identity
- 📱 Fully responsive design for different screen sizes
- 👜 Product showcase section
- 🔄 Carousel-style product display
- 💬 WhatsApp purchase button integration
- 🎨 Custom typography and styling
- ⚡ Lightweight project using only HTML and CSS

## Technologies

- HTML5
- CSS3

## Project Purpose

This project was created to practice building professional landing pages focused on product presentation, responsive layouts, and real-world business use cases.

## Deployment

The project can be deployed using platforms like Vercel or GitHub Pages.
